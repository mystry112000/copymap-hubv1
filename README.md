# ADHIHUB v2.1

Premium Roblox GUI Tool Suite

## Features

- **Save** — Save game with toggleable options (workspace, lighting, etc.)
- **Nice** — Password-protected save with custom file name
- **Fly** — Press E to toggle flight (WASD + Space/Q)
- **Noclip** — Press N to walk through walls
- **Misc** — Walk speed, jump power, destroy GUI

## Controls

| Key | Action |
|-----|--------|
| Right Control | Toggle GUI |
| E | Toggle Fly |
| N | Toggle Noclip |
| WASD | Move (while flying) |
| Space | Fly up |
| Q | Fly down |
